# 🌗 Context API Theme & Language Toggle (React + Vite + Tailwind)

A simple React project demonstrating how to use the **Context API** to manage global state—in this case, toggling between **Light** and **Dark** themes. Built with **Vite** and styled using **Tailwind CSS**.

---

## 🚀 Live Demo

> Deployed on [Vercel](https://context-theme-toggle.vercel.app/)

---

## 🧠 Features

- React Context API for global state management
- Toggle between light and dark themes
- Language selection (English & Hindi)
- Tailwind CSS for fast and clean styling
- Deployable to Vercel in seconds
